# Scheme catalog review checklist

For every scheme candidate, capture:

- Official scheme title, scope (Central / State), state code if State scheme, department / ministry
- Primary source page and any official guidelines PDF
- Summary, benefits, benefit amount / duration (if stated)
- Eligibility requirements with exact thresholds, exceptions, and scheme-specific questionnaire
- Required documents: mandatory vs conditional vs optional, plus acceptable alternatives if official guidance says so
- Application URL and clear application steps
- Effective dates / deadline, if any; data last checked date
- Source reviewer, second reviewer where feasible, review status
- User-facing disclaimer and fallback link to department source

Never mark `APPROVED` without human review of the primary source and the rules implementation. Treat outdated, ambiguous, or contradictory scheme information as `IN_REVIEW` or `EXPIRED`.
